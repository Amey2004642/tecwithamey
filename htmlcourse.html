Chapter 1: Introduction to HTML

1.1 What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages. HTML tells a web browser how the content of a webpage is organized — headings, paragraphs, images, links, lists and tables.

For example, when you visit a school website, HTML provides the structure for the school name, logo, admission information, notices and contact details.

1.2 Meaning of HTML

  • HyperText: Text that connects to other documents or web pages through hyperlinks.
  • Markup: Special tags used to identify and organize different types of content.
  • Language: A system of rules and instructions used to create documents.

1.3 Why is HTML used?

  1. Creating websites and web pages.
  2. Displaying text, headings and paragraphs.
  3. Adding images, audio and video.
  4. Creating hyperlinks between web pages.
  5. Organizing information into tables and lists.
  6. Creating forms for collecting user information.
  7. Providing structure for CSS styling and JavaScript functionality.

1.4 How does HTML work?

HTML Code → Structure and content → Web Browser reads and renders → Web Page displayed. Browsers such as Chrome, Firefox or Edge read HTML and render the page. Users see the webpage, not the HTML source.

1.5 Advantages of HTML

  • Easy to learn and use.
  • Supported by modern web browsers.
  • Works on different operating systems.
  • Can be combined with CSS and JavaScript.
  • Supports hyperlinks and multimedia.
  • No expensive software needed to get started.

1.6 Limitations of HTML

  • HTML alone does not provide advanced visual styling.
  • Cannot perform complex programming tasks by itself.
  • Does not independently store information in a database.
  • Interactive features often require JavaScript.
  • Modern responsive designs generally require CSS.

1.7 Example: First HTML webpage

first.html 
<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to HTML</h1>
    <p>I am learning web development.</p>

Output: A webpage displaying the heading “Welcome to HTML” and the paragraph “I am learning web development.”

Chapter 2: HTML Editors

2.1 What is an HTML editor?

An HTML editor is a software application used to write, edit and manage HTML code. HTML files are usually saved with the .html or .htm extension.

2.2 Types of HTML editors

1. Notepad

A simple text editor available on Windows. Students can use it to write HTML code manually and save it with the .html extension.

2. Visual Studio Code (VS Code)

A popular code editor offering syntax highlighting, code completion, extensions and debugging tools.

3. Notepad++

A lightweight source-code editor with syntax highlighting and useful editing features. Other options include Sublime Text and online editors such as the W3Schools Tryit Editor.

2.3 Steps to create an HTML file using Notepad

  1. Open Notepad.
  2. Type the HTML code.
  3. Click File → Save As.
  4. Enter the filename index.html.
  5. Select All Files as the file type, if required.
  6. Save the file in an easily accessible folder.
  7. Double-click the saved file or open it in a web browser.
  8. Edit the code in Notepad and refresh the browser to view changes.
Important: Ensure the file is saved as index.html, not index.html.txt.

2.4 HTML editor versus web browser

Chapter 3: Basic Structure of HTML

3.1 Standard HTML document structure

structure.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Webpage</title>
</head>
<body>
    <h1>My First Webpage</h1>
    <p>This is my first HTML document.</p>
</body>
</html>

3.2 Explanation of the tags

Tag or declarationExplanation
<!DOCTYPE html>Declares an HTML5 document.
<html>Root element containing the entire document.
lang="en"Identifies English as the main language.
<head>Contains metadata, title and resource links.
<meta charset="UTF-8">Specifies character encoding.
<meta name="viewport">Helps the page adapt to mobile screens.
<title>Sets the browser tab title.
<body>Main visible content.
<h1>Top-level heading.
<p>Paragraph.

3.3 Important points

  • The <!DOCTYPE html> declaration is not an ordinary HTML element.
  • Most HTML elements have opening and closing tags.
  • Elements should be nested correctly.
  • The page title belongs inside <head>.
  • Visible page content generally belongs inside <body>.

Chapter 4: HTML Elements and Tags

4.1 What is an HTML tag?

An HTML tag is a markup instruction written within angle brackets. Examples: <h1>, <p>, <img>, <a>.

4.2 What is an HTML element?

An element usually consists of an opening tag, content and a closing tag.

  • Closing tag: </p>

Inline elements stay within the current line and occupy only needed space. Examples: <span>, <a>, <strong>, <em>.

Chapter 19: HTML Head and Meta Elements

19.1 What is the <head> element?

The <head> element contains info about the document that is not normally displayed as page content: page title, character encoding, viewport settings, description, CSS links, favicon and other metadata.

19.2 What is metadata?

Metadata means information about the webpage. The <meta> element provides metadata used by browsers, search engines and other services.

Chapter 20: Responsive Web Design

20.1 What is responsive web design?

A responsive website adapts to different screen sizes and devices: desktop computers, laptops, tablets and mobile phones. HTML provides document structure and viewport metadata; CSS is primarily responsible for responsive layouts.

Chapter 22: Semantic HTML

22.1 What is semantic HTML?

Semantic HTML means using HTML elements according to their meaning and purpose. For example, <nav> identifies navigation content, while <footer> identifies footer content. Semantic elements help browsers, developers and assistive technologies understand page structure.

22.2 Common semantic elements

ElementPurpose
<header>Introductory content or section header.
<nav>Navigation links.
<main>Main content of the page.
<section>Thematic grouping of content.
<article>Independent or self-contained content.
<aside>Related supplementary content.
<footer>Footer information.
<figure>, <figcaption>Illustration with caption.
<time>Date or time.

22.3 Semantic HTML example

semantic.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>School Website</title>
</head>
<body>
    <header>
        <h1>ABC School</h1>
        <p>Learn, Grow and Succeed</p>
    </header>

    <nav>
        <a href="#home">Home</a>
        <a href="#about">About</a>
        <a href="#contact">Contact</a>
    </nav>

    <main id="home">
        <section id="about">
            <h2>About Our School</h2>
            <p>We provide quality education.</p>
        </section>

        <article>
            <h2>School News</h2>
            <p>Admissions are open for the new academic year.</p>
        </article>

        <aside>
            <h2>Notice</h2>
            <p>Please check the school timetable.</p>
        </aside>
    </main>

    <footer id="contact">
        <p>Contact: school@example.com</p>
    </footer>
</body>
</html>

22.4 Semantic elements versus <div>

A <div> is a generic container with no inherent semantic meaning. A <section> is a thematic section; an <article> is self-contained content. Use semantic elements when their meaning fits the content.

22.5 Advantages of semantic HTML

  • Makes code easier to read and maintain.
  • Helps assistive technologies.
  • Improves document organization.
  • Provides meaningful landmarks.
  • Helps search engines interpret content.

Practical: Create a school website using header, nav, main, section, article and footer.
