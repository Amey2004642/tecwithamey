SQL (Structured Query Language) is the standard language for communicating with relational databases. These notes cover everything from basic SELECT statements to JOINs, constraints, and security — arranged logically for practical learning.

Module 1: Introduction to SQL

1. What is SQL?

SQL allows us to create databases, store records, retrieve information, modify data, delete records, filter, sort, summarize, and connect related tables. Example: a college can use SQL to store student details and query students with marks above 80.

2. What is a database & table?

A database is an organized collection of data. A table stores related information in rows and columns. Below is a sample Students table:

SQL Syntax & Basic Queries

Core
10 lessons 5 exercises

SELECT, WHERE, ORDER BY

SELECT Statement

Retrieves data from a table:

SELECT Name, Marks FROM Students;

WHERE Clause

Filters records based on a condition:

SELECT * FROM Students WHERE Marks > 80;

ORDER BY

Sorts results ascending (ASC) or descending (DESC):

SELECT Name, Marks FROM Students ORDER BY Marks DESC;

Logical Operators (AND, OR, NOT)

SELECT * FROM Students WHERE Age = 17 AND Marks > 80;
Use parentheses to make complex conditions clear.

Insert, Update & Delete

DML
8 lessons 4 exercises

Data Manipulation

INSERT INTO

Adds new records:

INSERT INTO Students (StudentID, Name, Age, Marks) VALUES (105, 'Karan', 17, 81);

Insert multiple rows:

INSERT INTO Students (StudentID, Name, Age, Marks) VALUES (106, 'Riya', 18, 95), (107, 'Arjun', 17, 79);

UPDATE

Modifies existing records:

UPDATE Students SET Marks = 90 WHERE StudentID = 101;
Warning: Always use a WHERE clause. Without it, all rows will be updated.

DELETE

Removes records:

DELETE FROM Students WHERE StudentID = 105;

Delete all rows (structure remains):

DELETE FROM Students;

NULL Values

Find records with missing marks:

SELECT * FROM Students WHERE Marks IS NULL;
Use IS NULL or IS NOT NULL, never = NULL.

Aggregate Functions

Calculations
6 lessons 3 exercises

MIN, MAX, COUNT, SUM, AVG

Aggregate functions compute a single result from multiple rows.

FunctionPurposeExample Result
MIN()Lowest value76
MAX()Highest value92
COUNT()Number of rows4
SUM()Total sum341
AVG()Average value85.25

Examples

SELECT MIN(Marks) AS LowestMarks, MAX(Marks) AS HighestMarks, AVG(Marks) AS AverageMarks FROM Students;
Note: COUNT(*) counts all rows, while COUNT(column) ignores NULL values.

Combining Tables

A JOIN combines information from two or more tables using related columns.

INNER JOIN

Returns only records with matching values in both tables:

SELECT s.Name, d.DeptName FROM Students AS s INNER JOIN Departments AS d ON s.DeptID = d.DeptID;
NameDeptName
AmitCommerce
PriyaScience
RahulCommerce

LEFT JOIN

Returns all records from the left table, and matching records from the right table. If no match, right-table columns are NULL:

SELECT s.Name, d.DeptName FROM Students AS s LEFT JOIN Departments AS d ON s.DeptID = d.DeptID;

Result includes Neha with a NULL department name.

RIGHT JOIN

Returns all records from the right table, and matching records from the left table:

SELECT s.Name, d.DeptName FROM Students AS s RIGHT JOIN Departments AS d ON s.DeptID = d.DeptID;

Result includes Arts (DeptID 4) even though no student belongs to it.

FULL OUTER JOIN

Returns matching records and unmatched records from both tables:

SELECT s.Name, d.DeptName FROM Students AS s FULL OUTER JOIN Departments AS d ON s.DeptID = d.DeptID;
Note: MySQL does not support FULL OUTER JOIN directly; use a combination of LEFT and RIGHT joins.

SELF JOIN

Joins a table to itself. Useful for hierarchical data like employees and managers:

SELECT e.EmployeeName AS Employee, m.EmployeeName AS Manager FROM Employees AS e LEFT JOIN Employees AS m ON e.ManagerID = m.EmployeeID;

Grouping & Union

Combining
5 lessons 3 exercises

GROUP BY, HAVING, UNION

GROUP BY

Groups records with the same values so aggregate functions can summarize each group:

SELECT Department, SUM(Amount) AS TotalSales FROM Sales GROUP BY Department;

HAVING

Filters groups after grouping and aggregation:

SELECT Department, SUM(Amount) AS TotalSales FROM Sales GROUP BY Department HAVING SUM(Amount) > 50000;
ClausePurposeApplied
WHEREFilters individual rowsBefore grouping
HAVINGFilters groupsAfter grouping

UNION & UNION ALL

-- UNION removes duplicates SELECT Name FROM CurrentStudents UNION SELECT Name FROM FormerStudents;
-- UNION ALL retains duplicates SELECT Name FROM CurrentStudents UNION ALL SELECT Name FROM FormerStudents;
Rules: Each query must return the same number of columns with compatible data types.

Subqueries & Conditional Expressions

Advanced
7 lessons 3 exercises

EXISTS, ANY, ALL, CASE

EXISTS

Checks whether a subquery returns at least one row:

SELECT c.CustomerID, c.CustomerName FROM Customers AS c WHERE EXISTS ( SELECT 1 FROM Orders AS o WHERE o.CustomerID = c.CustomerID );

ANY & ALL

-- Price greater than at least one book price SELECT ProductName, Price FROM Products WHERE Price > ANY ( SELECT Price FROM Products WHERE Category = 'Books' ); -- Price greater than every book price SELECT ProductName, Price FROM Products WHERE Price > ALL ( SELECT Price FROM Products WHERE Category = 'Books' );

CASE Statement

Adds conditional logic to a query:

SELECT Name, Marks, CASE WHEN Marks >= 90 THEN 'Excellent' WHEN Marks >= 75 THEN 'Good' WHEN Marks >= 50 THEN 'Average' ELSE 'Needs Improvement' END AS Grade FROM Students;

Procedures & NULL Functions

SQL NULL Functions

FunctionDatabasePurpose
COALESCE()Most systemsReturns first non-NULL value
ISNULL()SQL ServerReplace NULL with value
IFNULL()MySQL, SQLiteReplace NULL with value
NVL()OracleReplace NULL with value
NULLIF()Many systemsReturns NULL if equal
-- Portable approach SELECT COALESCE(Marks, 0) FROM Students; -- NULLIF example SELECT NULLIF(10, 10); -- Returns NULL SELECT NULLIF(10, 5); -- Returns 10

Stored Procedures

A named set of SQL statements stored in the database:

-- SQL Server example CREATE PROCEDURE GetAllStudents AS BEGIN SELECT StudentID, Name, Marks FROM Students; END; EXEC GetAllStudents;
Note: Procedure syntax varies significantly between database systems (SQL Server, MySQL, PostgreSQL, Oracle).

Views & Security

SQL Views

A view is a named query that acts like a virtual table:

CREATE VIEW HighScorers AS SELECT StudentID, Name, Marks FROM Students WHERE Marks >= 85; -- Query the view SELECT * FROM HighScorers; -- Drop the view DROP VIEW HighScorers;
Note: A view is not automatically a security boundary. Permissions must be configured correctly.

SQL Injection Prevention

MethodDescription
Parameterized queriesPrimary defense; separates SQL from data
Input validationValidate according to expected format
Least privilegeGive accounts only necessary permissions
Avoid concatenationNever build SQL with untrusted input
Keep software updatedPatches fix known vulnerabilities

Parameterized Query Example (Python)

cursor.execute( "SELECT * FROM Users WHERE username = %s", (username,) )
Important: SQL parameters represent values, not table names or column names. Validate those against an allowlist.
